What crosses the boundary?

One Python string goes in. Rust releases the GIL, scans lines in parallel, and returns a compact map; PyO3 converts that map into a Python dictionary. Both timings include result conversion; the text fixture and regex setup are prepared before timing.

Run the example to compare tag counts and execution times.

The Python re and Rust regex patterns use the same rule. The Rust function uses Rayon across lines while Python's reference processes the corpus sequentially. Timings depend on available cores, machine, corpus, and crate/Python versions; this is not a universal speed claim.

The bridge between the two

So, what is maturin?

Maturin is a build tool for Python packages that contain Rust code. It compiles Rust into a native extension and packages it in a wheel that Python can install and import.

Implement performance-sensitive functions in a Rust crate.

Build with maturin

Maturin builds and installs the extension as part of a Python package.

In this project

Flask and the comparison logic stay in Python. The benchmark functions and collection aggregator are exposed by the compiled maturin_demo._native module through PyO3.
